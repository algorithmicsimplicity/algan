=============
Where To Next
=============

Congratulations on completing Algan's new-user tutorials!
You should now have everything you need to start
making videos of your own.

If you want to learn about more Algan functionality then
head on over to the advanced-user tutorials :doc:`advanced_user_tutorials` .
These tutorials are less structured and can be followed in any order.
In particular, check out the following useful tutorials:

  * :doc:`saving_videos_and_images` -- how to change the quality settings of your videos
  * :doc:`positioning_and_layout` -- all of the helpers for positioning mobs on screen
  * :doc:`images_and_textures` -- importing images, and painting images across surfaces
  * :doc:`shaders_and_materials` -- how to make convincing, realistic mobs
  * :doc:`audio_and_speech` -- adding sound to your videos

If you need help with Algan, or just want to chat with the developers and fellow Algan
users, then join the discord server: <discord_server>
