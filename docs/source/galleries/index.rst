=========
Galleries
=========

A catalogue of what Algan ships with, rather than an explanation of how it
works: every built-in Mob and every ready-made animation, each one shown as a
rendered clip beside the code that produced it.

Use them to find the thing you want, then follow the links into the tutorials
for how to drive it. If you are looking for the complete constructor arguments
instead, they are in the :doc:`reference manual <../reference>`.
