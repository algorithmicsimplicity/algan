###############
Example Gallery
###############

Algan's tutorials contain executable examples beside their rendered output.
Start with :doc:`new_user_tutorials/getting_started`, then continue through the
:doc:`new user tutorials <new_user_tutorials/index>` and
:doc:`advanced tutorials <advanced_user_tutorials/index>`.

The :doc:`reference manual <reference>` documents the modules behind those
examples. When adding a gallery-quality example, prefer the ``.. algan::``
directive so the source and rendered result remain linked and the example is
validated during a full documentation build.
